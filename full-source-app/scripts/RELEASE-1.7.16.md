# Veo Workflow Tools 1.7.16

- Bản phát hành thử nghiệm để xác nhận các máy đang dùng 1.7.15 nhận được thông báo cập nhật từ GitHub Releases.
- Không thay đổi tính năng so với 1.7.15; chỉ tăng phiên bản của ứng dụng và giữ nguyên kênh cập nhật public.

## Cách kiểm tra

Trên máy đang cài 1.7.15, mở **Veo Workflow Tools** và chờ kiểm tra cập nhật. Khi ứng dụng báo có 1.7.16, tải bản cập nhật rồi chọn **Khởi động lại** để áp dụng.

Nếu cần cài thủ công, tải `Veo-Workflow-Tools-Setup-1.7.16-x64.exe` từ GitHub Release. Gói cài không kèm profile, cookie, API key, lịch sử job hoặc database phát triển.
